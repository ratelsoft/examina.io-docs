# رمل المطور {#developer-sandbox}

إن صندوق حماية المطور examina.io هو مستأجر اختبار معزول يتم استضافته في
`https://sandbox.examina.io`. ويستخدم البنية التحتية لتطبيق الإنتاج
دون مشاركة اختبارات مؤسستك المباشرة والممتحنين والنتائج ومفاتيح API،
خطافات الويب، أو حالة الفوترة.

استخدمه للتحقق من صحة التزويد، والتخصيص، وجلسة الإطلاق، والنتائج، و
تكاملات webhook قبل إرسال حركة المرور المباشرة.

## افتح صندوق الرمل الخاص بك {#open-your-sandbox}

يمكن لكل منظمة حية استخدام صندوق رمل واحد. يمكن لأي مستخدم مؤسسة تم التحقق منه
افتحه:

1. قم بتسجيل الدخول إلى لوحة التحكم المباشرة.
2. افتح **الإعدادات → وضع الحماية للمطورين**.
3. حدد **فتح وضع الحماية**.

تقوم الزيارة الأولى بإنشاء صندوق الحماية المعزول تلقائيًا. examina.io إذن
يقوم بتسجيل دخولك إلى `sandbox.examina.io` باستخدام متصفح قصير العمر لمرة واحدة
عملية التسليم، لذلك لا توجد عادةً شاشة تسجيل دخول ثانية. عملية التسليم تحتوي على لا
كلمة المرور أو بيانات اعتماد الجلسة القابلة لإعادة الاستخدام ولا يمكن إعادة تشغيلها بعد الاستخدام.

يشير شعار **TEST MODE** المستمر ونمط الاختبار إلى أن التيار
لوحة القيادة تستخدم بيانات وضع الحماية. لا يوجد تبديل للبيئة: اسم المضيف
هي الحدود البيئية.

## قم بإنشاء مفتاح اختبار API {#create-a-test-api-key}

من وضع الحماية **الإعدادات**، أنشئ مفتاح اختبار محدد النطاق. تبدأ رموز الاختبار بـ
`exm_test.` وتظهر مرة واحدة فقط. أرسلها فقط إلى عنوان URL الأساسي لصندوق الحماية API:

```bash
curl --request GET \
  --header "Authorization: Bearer $EXAMINA_TEST_API_KEY" \
  --header "Accept: application/json" \
  "https://sandbox.examina.io/api/v1/exams"
```

يتم فرض الحدود في كلا الاتجاهين:

- مفاتيح `exm_test.` تعمل فقط على `sandbox.examina.io` وللاتصالات المرتبطة فقط
  مستأجر رمل.
- تم رفض مفاتيح `exm_live.` والمصادقة الأساسية القديمة بواسطة وضع الحماية.
- تم رفض مفاتيح الاختبار بواسطة API المباشر.

تتضمن أحداث خطاف الويب المعزولة الموقعة `"livemode": false` و
`"environment": "test"`، مما يسمح لأجهزة الاستقبال بإبعاد أحداث الاختبار عن البث المباشر
سير العمل في المصب.

استخدم نفس مسارات v1 وهيئات الطلب والنطاقات وسلوك القصور الموضح في
[API المرجع](../api/index.md).

## حدود وضع الحماية {#sandbox-limits}

إن صندوق الحماية للبنية التحتية المشتركة صغير الحجم ومجاني عن عمد:

| الموارد | الحد |
| --- | ---: |
| الممتحنين | 1 |
| الامتحانات النشطة | 3 |
| المجموعات | 3 |
| محاولات الامتحان | 5 لكل فترة 30 يومًا |
| جلسات الامتحان المتزامنة | 1 |
| الاحتفاظ بالنتيجة المكتملة | 30 يوما |
| طلبات API | 120 لكل مفتاح اختبار في الدقيقة |
| إعادة تعيين وضع الحماية | 3 في اليوم |

لا تقوم محاولات Sandbox أبدًا بحجز الأموال أو استهلاك مخصصات الخطة المدفوعة أو كتابة الاستخدام
دفاتر الأستاذ، أو إنشاء رسوم الميزات القابلة للفوترة. إعادة الاتصال بنفس المحاولة
لا يستهلك فتحة بدل أخرى.

الميزات الخارجية المدفوعة مثل المراقبة المباشرة والتحقق من الهوية هي
غير متوفر في رمل. تم تعطيل تسليم البريد الإلكتروني وتسجيله.

## إعادة تعيين بيانات الاختبار {#reset-test-data}

يمكن للمسؤول استخدام **إعادة تعيين وضع الحماية** من إعدادات وضع الحماية حتى ثلاثة
مرات في اليوم الواحد. إعادة تعيين يزيل
اختبارات الاختبار، الممتحنين، المجموعات، الواجبات، النتائج، تكوين webhook،
سجلات التسليم وملفات وضع الحماية التي تم تحميلها.

إعادة التعيين يحفظ عمدا:

- مستأجر رمل؛
- مفاتيح `exm_test.` ذات النطاق؛ و
- الاستخدام الحالي لبدل المحاولة لمدة 30 يومًا.

يؤدي الحفاظ على البدل إلى منع إعادة التعيين من أن تصبح وسيلة لتجاوز السعة المجانية
حد الاستخدام. قم بإلغاء المفاتيح بشكل منفصل عندما لا تكون هناك حاجة إليها.

## الاحتفاظ بالبيانات وفهرستها {#data-retention-and-indexing}

تتم إزالة نتائج وضع الحماية المكتملة تلقائيًا بعد 30 يومًا. رمل
ترسل الصفحات `X-Robots-Tag: noindex, nofollow`؛ محتوى اختبار المستأجر غير مقصود
لفهرسة البحث. تظل وثائق المطور العامة قابلة للفهرسة في
`docs.examina.io`.

## سير عمل التكامل الموصى به {#recommended-integration-workflow}

1. البناء على `https://sandbox.examina.io/api/v1` باستخدام مفتاح `exm_test.`.
2. ممارسة النجاح، والتحقق من الصحة، والعجز، وإعادة المحاولة، ومسارات التوقيع على الويب.
3. تأكد من أن التكامل الخاص بك يتعامل مع استجابات حصص صندوق الحماية دون تكرار حلقات إعادة المحاولة.
4. قم بإنشاء مفتاح `exm_live.` منفصل مع الحد الأدنى من النطاقات المطلوبة.
5. قم بتغيير عنوان URL الأساسي والسر من خلال النشر الخاص بالبيئة
   التكوين؛ لا تقم أبدًا بتحويل رمز الاختبار إلى رمز حي.

بالنسبة للطلبات الجاهزة للنسخ والاختبار الأول الكامل، اتبع
[صندوق الرمل API التشغيل السريع](sandbox-api-quickstart.md).

## استكشاف أخطاء الوصول وإصلاحها {#troubleshoot-access}

إذا انتهت صلاحية عملية التسليم التلقائي أو تم استخدامها بالفعل، فارجع إلى البث المباشر
صفحة إعدادات **وضع الحماية للمطورين** وحدد **فتح وضع الحماية** مرة أخرى. تسليم
تنتهي صلاحيته بعد 90 ثانية. يبقى تسجيل الدخول المباشر على `sandbox.examina.io`
متاح كاحتياطي.

إذا أعادت مكالمات API HTTP 429، فانتظر فترة `Retry-After` قبل إعادة المحاولة.
استخدم التراجع الأسي المحدود ولا تبدأ حلقات إعادة المحاولة المتوازية.
