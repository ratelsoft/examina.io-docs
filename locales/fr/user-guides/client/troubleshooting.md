# Dépannage le jour du test {#test-day-troubleshooting}

Suivez d'abord les instructions de l'organisateur. Si l'examen est chronométré ou surveillé,
informer le surveillant ou le contact d’assistance dès qu’un problème survient.

## Capturez des informations utiles {#capture-useful-information}

Avant de modifier quoi que ce soit, notez :

- le message d'erreur exact ;
- l'heure et le fuseau horaire actuels ;
- le titre de l'examen ;
- votre code candidat, sans le mot de passe ;
- le navigateur et l'appareil ; et
- la dernière action réussie.

Ne publiez pas d’informations d’identification, de documents d’identité ou d’images de surveillance dans un
canal d'assistance non approuvé.

## Le lien de l'examen ne s'ouvre pas {#the-exam-link-does-not-open}

1. Copiez à nouveau le lien complet du message de l'organisateur.
2. Vérifiez que le navigateur n'a pas omis le début ou la fin du lien.
3. Confirmez que l'appareil est en ligne en ouvrant un autre site autorisé.
4. Essayez le lien dans un navigateur pris en charge à jour.
5. Demandez à l'organisateur si l'examen est visible et toujours actif.

## Le code ou le mot de passe est rejeté {#code-or-passcode-is-rejected}

- Entrez les deux valeurs exactement telles que fournies.
- Vérifiez les espaces accidentels avant ou après une valeur copiée.
- Confirmez que les informations d'identification appartiennent à cet examen et à vous.
- Évitez les suppositions répétées ; demandez à l'organisateur de vérifier ou de réinitialiser les informations d'identification.

## L'examen n'est pas disponible {#the-exam-is-unavailable}

L'examen peut être invisible, pas encore à son heure de début cartographiée, attribué dans un autre
fuseau horaire, ou manquer votre candidat ou votre cartographie papier. Contactez l'organisateur au
le titre de l'examen et votre code afin qu'ils puissent vérifier Manager.

## La caméra, le microphone ou le partage d'écran échouent {#camera-microphone-or-screen-sharing-fails}

1. Vérifiez que la bonne caméra et le bon microphone sont connectés.
2. Autorisez les autorisations du navigateur demandées par la page d'examen.
3. Fermez les autres applications à l'aide de la caméra ou du microphone.
4. Rechargez uniquement si l'organisateur ou la page vous le demande.
5. Si l'autorisation a été précédemment bloquée, ouvrez les autorisations du navigateur du site
   et remplacez l'élément bloqué par Autoriser.

Ne passez pas à un appareil interdit juste pour contourner un contrôle.

## La connexion Internet est interrompue {#internet-connection-is-interrupted}

1. Gardez l'onglet examen ouvert.
2. Restaurez le Wi-Fi ou la connexion filaire.
3. Évitez de répondre à d'autres questions si le client signale clairement qu'il ne peut pas
   sauvegarder, sauf indication contraire de l’organisateur.
4. Attendez que la page signale la reconnexion.
5. Avertissez le surveillant et donnez l'heure approximative de déconnexion.

Le client enregistre périodiquement lorsqu'il est connecté, mais le travail est terminé après le dernier
une sauvegarde réussie peut être compromise en cas de panne prolongée ou de coupure de courant.

## La page se fige ou devient vierge {#the-page-freezes-or-becomes-blank}

- Attendez brièvement une sauvegarde ou une soumission en cours.
- Vérifiez la connexion sans fermer l'onglet examen.
- Prenez une capture d'écran qui exclut les informations d'identification ou les données d'identité privées.
- Contactez l'assistance avant d'actualiser, de vous déconnecter ou d'ouvrir l'examen sur un
  deuxième appareil.

## Le minuteur ou le papier semble incorrect {#the-timer-or-paper-looks-wrong}

Arrêtez-vous et contactez l'organisateur si la durée, le nom du papier, les papiers disponibles ou
le nombre de questions est en conflit avec les instructions. Inclure un coffre-fort de confidentialité
capture d'écran si demandé.

## La soumission ne se termine pas {#submission-does-not-finish}

1. Gardez la page ouverte.
2. Confirmez que l'appareil est en ligne.
3. Attendez un message de fin ou de résultat.
4. Informez immédiatement le surveillant si le minuteur expire ou si la page reste
   coincé.
5. Ne soumettez pas à plusieurs reprises et ne commencez pas une deuxième session, sauf indication contraire.

L'organisateur peut examiner votre état actuel dans Manager et déterminer le prochain
étape.
