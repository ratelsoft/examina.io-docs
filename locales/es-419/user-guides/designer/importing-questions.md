# Reutiliza el contenido del proyecto

Designer puede volver a abrir un proyecto editable `.smexproj` y duplicar pruebas o preguntas dentro del proyecto abierto. Estas son las formas admitidas para adaptar el contenido existente en la versión actual.

## Abre un proyecto guardado

1. Selecciona **Archivo → Abrir proyecto**.
2. Elige el archivo `.smexproj` guardado por Designer.
3. Revisa sus exámenes, pruebas y preguntas en **Exam Explorer**.
4. Selecciona **Archivo → Guardar proyecto como** antes de hacer cambios sustanciales.

El archivo editable `.smexproj` es diferente del paquete de entrega `.smex` exportado para Manager. Abre el archivo de proyecto en Designer; importa el paquete de entrega en Manager.

## Duplica una prueba

1. Haz clic derecho en la prueba de origen y selecciona **Copiar**.
2. Haz clic derecho en el examen de destino y selecciona **Pegar prueba**.
3. Cambia el nombre de la nueva prueba para que su título sea único dentro del examen.
4. Revisa la duración, las instrucciones, las secciones, la selección de preguntas y la configuración de la calculadora.

La copia se mantiene editable y no altera la prueba de origen.

## Duplica una pregunta

1. Haz clic derecho en la pregunta de origen y selecciona **Copiar**.
2. Haz clic derecho en la prueba de destino y selecciona **Pegar pregunta**.
3. Actualiza la consigna, la respuesta, el puntaje y la sección según sea necesario.
4. Previsualiza la pregunta copiada antes de exportar.

Copiar y pegar funcionan dentro del proyecto actualmente abierto.

## Contenido fuera de este proyecto

Para traer exámenes de otro proyecto, pruebas de un examen exportado o preguntas redactadas en un documento de Word, RTF o texto, usa el asistente de importación en lugar de copiar y pegar. Consulta [Importar contenido existente](import-content.md).

## Valida el contenido reutilizado

Después de copiar contenido:

1. verifica si hay títulos de exámenes o pruebas duplicados;
2. verifica el tipo de pregunta, la respuesta, el puntaje y la sección;
3. previsualiza el formato, las ecuaciones, las imágenes y el audio;
4. vuelve a comprobar la duración de la prueba y la cantidad de preguntas por responder;
5. lee y corrige las instrucciones; y
6. guarda el proyecto con un nuevo nombre antes de exportar.
