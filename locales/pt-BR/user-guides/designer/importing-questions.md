# Reutilizar conteúdo de projetos

O Designer pode reabrir um projeto `.smexproj` editável e duplicar provas ou questões dentro do projeto aberto. Estas são as maneiras suportadas para adaptar conteúdos existentes na versão atual.

## Abrir um projeto salvo

1. Selecione **Arquivo → Abrir Projeto**.
2. Escolha o arquivo `.smexproj` salvo pelo Designer.
3. Revise seus exames, provas e questões no **Exam Explorer**.
4. Selecione **Arquivo → Salvar Projeto Como** antes de fazer alterações significativas.

O arquivo editável `.smexproj` é diferente do pacote de aplicação `.smex` exportado para o Manager. Abra o arquivo de projeto no Designer; importe o pacote de aplicação no Manager.

## Duplicar uma prova

1. Clique com o botão direito na prova de origem e selecione **Copiar**.
2. Clique com o botão direito no exame de destino e selecione **Colar Prova**.
3. Renomeie a nova prova para que seu título seja exclusivo no exame.
4. Revise duração, instruções, seções, seleção de questões e configurações da calculadora.

A cópia permanece editável e não altera a prova de origem.

## Duplicar uma questão

1. Clique com o botão direito na questão de origem e selecione **Copiar**.
2. Clique com o botão direito na prova de destino e selecione **Colar Questão**.
3. Atualize o enunciado, resposta, pontuação e seção conforme necessário.
4. Visualize a questão copiada antes de exportar.

Copiar e colar funcionam dentro do projeto atualmente aberto.

## Conteúdo externo a este projeto

Para trazer exames de outro projeto, provas de um exame exportado ou questões digitadas em um documento Word, RTF ou de texto, use o assistente de importação em vez de copiar e colar. Veja [Importar conteúdo existente](import-content.md).

## Validar conteúdo reutilizado

Após copiar o conteúdo:

1. verifique se há títulos de exames ou provas duplicados;
2. verifique o tipo de questão, resposta, pontuação e seção;
3. visualize formatação, equações, imagens e áudio;
4. verifique novamente a duração da prova e a contagem de questões a responder;
5. revise as instruções; e
6. salve o projeto com um novo nome antes de exportar.
