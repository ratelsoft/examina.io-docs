# API reference

The production build replaces this page with the interactive API reference
generated from [`reference/examina.io.v1.yaml`](https://github.com/ratelsoft/examina.io-docs/blob/main/reference/examina.io.v1.yaml).

All API requests use HTTPS and Basic Authentication. Use `api` as the username
and your API secret key as the password. Never place the secret key in browser
code, a public repository, or a mobile application.
