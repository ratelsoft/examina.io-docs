# Groups and exam assignments

Manager uses **Groups** for reusable collections of examinees and **mappings**
to decide which exam papers each examinee may take.

## When to use a Group

Create a Group for a set of people you regularly handle together, such as:

- a course or class;
- an intake or cohort;
- an assessment center;
- a department; or
- a scheduled sitting.

A Group does not grant staff permissions. Use a [Circle](../administration/circles-and-permissions.md)
for access control.

## Create a Group

1. Open **Manager**.
2. Select **File → Create New Group**.
3. Enter a unique name and a useful description.
4. Save the Group.
5. Select the Group, then add examinees from the searchable list.

You can also add Group membership from an examinee record or assign imported
examinees to a Group during file import.

## Map one examinee to an exam

1. Open the **Examinees** tab and select the person.
2. Choose the action to map the examinee to an exam.
3. Search for and select one exam.
4. Continue to paper mapping.
5. Select the papers the examinee may take.
6. Optionally assign the earliest exam time and choose the correct time zone.
7. Save the mapping.

Only one exam is selected in a single mapping operation, but you can map the
same examinee to additional exams in later operations.

## Map several examinees from an exam

1. Open the **Exams** tab and select the exam.
2. Choose **Map Examinees**.
3. Search for examinees by name, code, or an available additional field.
4. Move the intended examinees to the selected list.
5. Continue to paper mapping.
6. Choose the papers and optional start time.
7. Save the mappings.

## Map a Group

You can begin from either the exam or Group:

- Select an exam and choose **Map Groups**; or
- select a Group and choose **Map Group to Exam**.

When mapping a Group, Manager applies the assignment to current Group members
who are not already mapped to that exam. Adding someone to the Group later does
not imply that every past mapping operation is automatically repeated, so
review the exam's mapped examinees after membership changes.

## Choose papers and time carefully

The selected papers are the papers the examinee can take in Client. If an exam
contains several papers, confirm that every candidate has the correct
combination.

The optional mapped start time is the earliest time the exam is available for
that assignment. Always verify:

- calendar date;
- local time;
- time zone;
- daylight-saving implications; and
- whether candidates in different regions need separate assignments.

## Verify mappings

Before publishing an exam:

1. Open the exam's mapped-examinee list.
2. Compare its count with the intended roster.
3. Spot-check paper assignments.
4. Check start times and time zones.
5. Confirm that withdrawn or duplicate candidates are not present.
6. Test with an examinee account that has the same paper pattern.

Deleting a mapping removes the assignment; it does not delete the underlying
examinee or Group.
