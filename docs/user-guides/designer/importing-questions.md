# Reuse project content

Designer can reopen an editable `.smexproj` project and duplicate papers or
questions inside the open project. These are the supported ways to adapt
existing content in the current release.

## Open a saved project

1. Select **File → Open Project**.
2. Choose the `.smexproj` file saved by Designer.
3. Review its exams, papers, and questions in **Exam Explorer**.
4. Select **File → Save Project As** before making substantial changes.

The editable `.smexproj` file is different from the `.smex` delivery package
exported for Manager. Open the project file in Designer; import the delivery
package in Manager.

## Duplicate a paper

1. Right-click the source paper and select **Copy**.
2. Right-click the destination exam and select **Paste Paper**.
3. Rename the new paper so its title is unique within the exam.
4. Review duration, instructions, sections, question selection, and calculator
   settings.

The copy remains editable and does not alter the source paper.

## Duplicate a question

1. Right-click the source question and select **Copy**.
2. Right-click the destination paper and select **Paste Question**.
3. Update the prompt, answer, score, and section as needed.
4. Preview the copied question before export.

Copy and paste operate within the currently open project.

## Content from outside this project

To bring in exams from another project, papers from an exported exam, or
questions typed out in a Word, RTF, or text document, use the import wizard
instead of copy and paste. See [Import existing content](import-content.md).

## Validate reused content

After copying content:

1. check for duplicate exam or paper titles;
2. verify question type, answer, score, and section;
3. preview formatting, equations, images, and audio;
4. recheck paper duration and questions-to-answer counts;
5. proofread instructions; and
6. save the project under a new name before export.
